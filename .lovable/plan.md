# AI for Everyone — One-page event agenda

## Goal
Create a refined, energetic one-page agenda for the 22 September 2026 dinner event at Cipriani 42nd Street, using the supplied MWL references and available portraits.

## Page structure
- A bright first view with the MWL identity, event title, date, venue, and a direct jump to the agenda.
- A flowing evening timeline from registration through the networking reception.
- Expanded panel entries that keep speaker names, roles, and moderators easy to scan.
- A speaker portrait gallery using the uploaded photographs; speakers without portraits remain elegantly represented by name until their images arrive.
- A concise venue and event-details finish.

## Visual direction
- Light ivory canvas with deep teal, emerald, and restrained MWL gold accents drawn from the supplied references.
- Bold editorial typography, curved fan-inspired graphic forms, crisp rules, and generous spacing.
- Subtle entrance and timeline animations, with reduced-motion support.
- Responsive composition for phone and desktop, without a dark theme.

## Technical details
- Use the uploaded portraits through project-managed image assets.
- Keep all color, type, shadow, and motion values in the shared design system.
- Add page-specific title and sharing metadata.
- Verify the finished page visually at desktop and mobile sizes.
